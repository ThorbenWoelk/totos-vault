## Main claim

One reason multi-agent systems can outperform simpler setups is that they allocate more inference effort to
the problem.

An Anthropic engineering analysis attributed 95% of performance variance to three factors: token usage, number
of tool calls, and model choice. Token usage alone explained 80% in that analysis.
