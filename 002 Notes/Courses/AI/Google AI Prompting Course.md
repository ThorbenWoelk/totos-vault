## Fundamental framework

The mnemonic **Tiny Crabs Ride Enormous Iguanas** represents:

1. Task
2. Context
3. References
4. Evaluate
5. Iterate

## Iteration checklist

The mnemonic **Ramen Saves Tragic Idiots** captures four ways to revise a prompt:

- Revisit the fundamental prompting framework.
- Separate one long prompt into shorter, focused prompts.
- Rephrase the task through an analogy; for example, ask for a story instead of a marketing plan.
- Introduce explicit constraints.

## Advanced techniques

- **Prompt chaining:** Use one model response as input for the next step.
- **Chain-of-thought prompting:** Ask the model to work through a problem step by step.
- **Tree-of-thought prompting:** Ask the model to explore several candidate approaches, such as three
different design perspectives.
